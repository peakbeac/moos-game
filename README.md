# Coral County

A browser driving sandbox in the blocky spirit of a Roblox open world. You start on Shell Beach. The county is split into four regions — beach, desert, big city, and mountains — and you can cross it by car, train, plane, or helicopter.

The blue **Lumen iX** parked beside the spawn is an original electric coupe-SUV shaped after the BMW iX: tall shield face, black roof, copper belt line, and a strong low-speed pull. It is not a BMW product and it does not use BMW badges.

## Run it

```bash
npm install
npm run dev
```

Open the URL Vite prints (port **47321**).

```bash
npm run build
npm run preview
```

## How to play

| Action | Control |
| --- | --- |
| Move / steer | WASD or arrow keys, or the left stick on a phone |
| Look | Drag the mouse |
| Enter, exit, read a sign | F or Enter |
| Jump / handbrake / climb | Space |
| Helicopter down | C |
| Boost (cars) | Shift |
| Headlights | L |
| Horn | H |
| Map and beacon | M, then click or pick a place |
| Reset the current ride | R |
| Mute | N |

Planes use W and S for throttle and the arrow keys to pitch the nose. Helicopters hover when you release the controls. The Gull Trainer starts lined up on runway 09 at Red Mesa Field.

## What's on the map

- **Shell Beach** — spawn, pier and lighthouse, helipad, Palm Circuit.
- **Red Mesa desert** — runway, three showroom aircraft, Mesa Oval, Dune Fuel.
- **Big City** — grid with working traffic lights, Pinfall bowling and arcade, Starlight Cinema, County General (roof helipad), downtown towers, County Circle.
- **Mountains** — ridge road, a short tunnel, Ridge Loop, Ridge Lodge, SkyCam pad.
- **Tide Line** — a commuter train that stops at four stations, Copper Haul freight on the outer loop, and the drivable Rail Bug on the inner rail.
- Railroad crossings drop their arms and flash when a train is close.
- Three race tracks keep a lap timer once you cross the stripe in the right direction.

Traffic on Ocean Avenue and Shore Highway stops for red lights. Blowing a red in a car adds a ticket. It does not stop the car.
